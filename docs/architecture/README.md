# NuurMart Architecture

Modular monorepo with separate Frontend and Backend applications.

Frontend:
- App Router for routing
- Feature-based domain organization
- Shared reusable UI components

Backend:
- Domain modules
- Express REST API
- MongoDB through Mongoose
- Environment validation
- Centralized middleware (upcoming)

Development sequence:
1. Foundation
2. Premium storefront UI
3. Product and category API
4. Shopping cart and checkout
5. Admin dashboard
6. Authentication, security and deployment
