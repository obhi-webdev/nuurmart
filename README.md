# NuurMart

Premium Grocery & Organic Food E-commerce Platform.

## Stack
- Next.js, React, TypeScript, Tailwind CSS
- Node.js, Express, TypeScript
- MongoDB Atlas, Mongoose

## Development
npm run dev

Frontend: http://localhost:3000
Backend health: http://localhost:5001/api/health

## Architecture
- frontend: Storefront and admin interface
- backend: REST API and business modules
- docs: Design, API and architecture documentation
- scripts: Development utilities

## Status
Phase 1: Foundation setup.
Real checkout, payments and order persistence are not yet implemented.
